# OWNERSHIP.md — who may touch which files

> Enforced by `python scripts/check_ownership.py --role D` (or `--role V`) before every push. A file outside your list, a LOCKED file, or an unlisted new path = violation. Need something changed in the other person's file? Ask in chat; they make the change.

| `.env.example`, `.gitignore`, `requirements.txt` | |

## Shared, append-only (both)
| Path | Rule |
|---|---|
| `docs/FRICTION_LOG.md` | append new entries only; never edit or delete the other person's entries |
| `DECISION.md` | append architectural decisions and codebase understanding entries |

## LOCKED (nobody edits without agreement)
`BUILD.md`, `BUILD_D.md`, `BUILD_V.md`, `INTEGRATION.md`, `SETUP.md`, `OWNERSHIP.md`, `.github/CODEOWNERS`.
Change them only in a commit whose message starts with `CONTRACT-CHANGE:` after the other person says "ok" in chat. Run the checker with `--contract-change` for that commit.

## Never touched by anyone
`artifacts/` (git-ignored output), `.env` (git-ignored secrets), `.venv/`, `node_modules/`.

## New files
Not allowed unless they fall under your list above. A new path is reported as "unowned". Ask first and add it here under a `CONTRACT-CHANGE:` commit.
